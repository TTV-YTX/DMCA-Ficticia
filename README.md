# Bienvenido

La DMCA Ficticia es una DMCA para bloquear algunos canales de Señal Libre, TeleBox Live, Flow Digital Maker, Etc.

## Derechos de autor o copyright

Los canales de algunas Compañías Ficticias que tienen copyright serán bloqueadas de las páginas Webs Ficticias (Como por ejemplo:TeleSostificado) Ya que no se pueden ver por qué la tienen bloqueados por el copyright

### Músicas Copyright

Si un Canal tiene una música de copy será bloqueada para no ver
